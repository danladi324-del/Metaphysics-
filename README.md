# Metaphysics

A personal, offline iPhone web app that calculates (natal chart, transits, numerology, moon and planetary hours, I Ching, tarot, BaZi, Tzolk'in, Vedic, Feng Shui, geomancy), keeps interpretation separate and sourced, logs where conventions and sources disagree, and reports daily without manufacturing consensus.
